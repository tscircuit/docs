## Overview

The `<silkscreenline />` element draws a straight line segment between `(x1, y1)` and `(x2, y2)` on the PCB silkscreen layer. It is ideal for drawing polarity bars on diodes and polarized capacitors, notched package outlines, or keep-clear tick marks around pads.

  defaultView="pcb"

          <silkscreenline x1="-2.2mm" y1="0.9mm" x2="2.2mm" y2="0.9mm" strokeWidth="0.15mm" />
          <silkscreenline x1="-2.2mm" y1="-0.9mm" x2="2.2mm" y2="-0.9mm" strokeWidth="0.15mm" />
          <silkscreenline x1="0.7mm" y1="-0.9mm" x2="0.7mm" y2="0.9mm" strokeWidth="0.25mm" />

      }

  </board>
)

## Properties

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `x1` | `length` | *required* | X coordinate of the line start point |
| `y1` | `length` | *required* | Y coordinate of the line start point |
| `x2` | `length` | *required* | X coordinate of the line end point |
| `y2` | `length` | *required* | Y coordinate of the line end point |
| `strokeWidth` | `length` | `"0.1mm"` | Width of the silkscreen line |
| `layer` | `"top" \| "bottom"` | `"top"` | PCB layer on which the silkscreen line is placed |
