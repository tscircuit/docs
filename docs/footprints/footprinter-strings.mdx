## Overview

You can quickly specify the footprint and 3d model for any element by setting
the `footprint` property to a string. Footprinter strings use a compact underscore-separated syntax (`<package><pins>_<param><value>`) to customize pitch, pad dimensions, body width, drill sizes, and thermal pads.

<FootprintPreview footprint="0402" />

### Common Parameter Modifiers

| Modifier | Example | Meaning |
| --- | --- | --- |
| `p<length>` | `soic8_p1.27mm` | Center-to-center pin pitch |
| `w<length>` | `soic8_w3.9mm` | Package body width |
| `h<length>` | `qfn16_w3mm_h3mm` | Package body height |
| `pw<length>` | `0603_pw0.8mm` | Individual SMD pad width |
| `pl<length>` | `0603_pl0.9mm` | Individual SMD pad length |
| `id<length>` | `dip8_id0.8mm` | Plated hole inner (drill) diameter |
| `od<length>` | `dip8_od1.6mm` | Plated hole outer (annular ring) diameter |
| `thermalpad` | `qfn32_thermalpad3.1x3.1mm` | Centered exposed thermal pad (default or `WxH`) |

## bga

Ball Grid Array (BGA) footprint.

<FootprintPreview footprints={["bga9", "bga16_p2mm", "bga14_p1.5mm_missing(1,2)"]} />

**Parameters:**

| Parameter   | Default       | Description                                                                      |
|-------------|---------------|----------------------------------------------------------------------------------|
| `num_pins`  | `64`          | Total number of solder balls.                                                    |
| `grid`      | _calculated_  | Grid dimensions as an object (e.g. `{ x: N, y: N }`). If unspecified, a square grid is assumed. |
| `p`         | `"0.8mm"`     | Ball pitch: center-to-center distance between adjacent balls.                   |
| `w`         | _none_        | Package width (optional).                                                        |
| `h`         | _none_        | Package height (optional).                                                       |
| `ball`      | _none_        | Ball diameter (optional).                                                        |
| `pad`       | _none_        | Pad size for each ball (optional).                                               |
| `tlorigin`  | `false`       | Use top-left numbering for balls.                                                |
| `blorigin`  | `false`       | Use bottom-left numbering for balls.                                             |
| `trorigin`  | `false`       | Use top-right numbering for balls.                                               |
| `brorigin`  | `false`       | Use bottom-right numbering for balls.                                            |
| `missing`   | `[]`          | List of balls to omit (by number or position) to accommodate design needs.       |

## tqfp

<FootprintPreview footprints={["tqfp32", "tqfp44", "tqfp64"]} />

Parameters:

| Parameter | Default | Description |
|-----------|---------|-------------|
| `num_pins` | `32` | Total number of pins (must be divisible by 4). Common values: 32, 44, 48, 64, 80, 100, 144 |
| `p` | _varies_ | Pin pitch. Defaults: 0.8mm for 32-pin, 0.5mm for 44+ pins |
| `pl` | _varies_ | Pin length. Defaults based on pin count: 1.475mm for 32-100 pins, 1.6mm for 144 pins |
| `pw` | _varies_ | Pin width. Defaults based on pin count: 0.55mm (32-pin), 0.3mm (44-100 pins), 0.25mm (144-pin) |
| `w` | _inherited_ | Package width (inherited from quad base) |
| `h` | _inherited_ | Package height (inherited from quad base) |
