---
title: <assembly.device />
description: Group boards and mechanical parts into a complete device.
---

Import the `assembly` namespace from `@tscircuit/core` to describe a device containing boards, displays, and mechanical parts.

```tsx
import { assembly } from "@tscircuit/core"

export default () => (
  <assembly.device name="product" modelUrl="/housing.glb">
    <board name="B1" width="40mm" height="30mm" />
  </assembly.device>
)
```

Replace `/housing.glb` with your own model URL, accessible to the viewer. Relative asset URLs are resolved using the platform's `projectBaseUrl`.

Without `modelUrl`, `assembly.device` is a transparent container. With `modelUrl`, it renders a CAD model at the world origin without creating PCB pads or schematic symbols. Boards and other children keep their own rendering behavior; the device model does not reposition them. Devices can be nested; `assembly.screen` attachment selectors are scoped to their nearest device.

| Property | Description |
|----------|-------------|
| `name` | Optional device name. |
| `modelUrl` | Optional imported CAD model URL, rendered at the world origin. |
| `children` | Boards, subassemblies, screens, or nested devices. |

## Assembly elements

| Element | Purpose |
|---------|---------|
| [`assembly.subassembly`](./assembly-subassembly.mdx) | Group imported mechanical models and CAD children. |
| [`assembly.cadassembly`](./assembly-cadassembly.mdx) | Alias for `assembly.subassembly`. |
| [`assembly.screen`](./assembly-screen.mdx) | Place a display relative to a connector or another assembly. |

See [Mounting 3D models to a board](../guides/tscircuit-essentials/mounting-3d-models.mdx) for a board with mounting holes and imported screws.

`modelUrl` uses the same file formats as [`cadmodel`](./cadmodel.mdx): GLB, GLTF, OBJ, STL, STEP/STP, and WRL/VRML. Use a `#ext=glb` suffix when the URL does not include the file extension. For model offsets or other advanced options, place a `cadmodel` inside an `assembly.subassembly`.
