`assembly.device` groups boards and mechanical parts into a complete device. Add `model` or `modelUrl` to render a model at the world origin.

<CircuitPreview
  wrapCode
  circuitJson={preview1}
  defaultView="3d"
  hideSchematicTab
  browser3dView={false}
  code={`import { assembly } from "tscircuit"

const models =
  "https://docs.tscircuit.com/models/assembly"

export default () => (
  <assembly.device
    name="product"
    modelUrl={models + "/housing.glb"}
  >
    <board name="B1" width="40mm" height="30mm" />
  </assembly.device>
)`}
/>

| Property | Description |
|----------|-------------|
| `name` | Optional device name. |
| `model` | Modelprinter string or HTTP(S) model URL. |
| `modelUrl` | Imported CAD model URL. Use either `model` or `modelUrl`. |
| `children` | Boards, motors, subassemblies, and screens. |

## Modelprinter strings

Use a modelprinter string to generate a model without supplying a file. This display is 16 × 10 mm with a 5 mm cable.

Assembly models add 3D geometry without creating PCB footprints or electrical connections. For imported models, see [`cadmodel`](./cadmodel.mdx) for supported formats.

Use [`assembly.motor`](./assembly-motor.mdx) to add a motor and mount a controller to its backface, [`assembly.subassembly`](./assembly-subassembly.mdx) to group mechanical parts, or [`assembly.screen`](./assembly-screen.mdx) to attach a display to a connector. See [Mounting 3D models](../guides/tscircuit-essentials/mounting-3d-models.mdx) for screws aligned with board holes.
