`assembly.screen` places a display model relative to a PCB component or another assembly. `connectsTo` controls its position and orientation; it does not create electrical connections.

<CircuitPreview
  wrapCode
  circuitJson={preview1}
  defaultView="3d"
  hideSchematicTab
  browser3dView={false}
  code={`import { assembly } from "@tscircuit/core"

export default () => (
  <assembly.device name="product">
    <board
      name="B1"
      width="44mm"
      height="36mm"
      thickness="1.6mm"
      routingDisabled
    >
      <connector
        name="J1"
        pcbY={-13}
        pinCount={30}
        footprint="fpc30_p0.5mm"
      />
    </board>
    <assembly.screen
      name="SCREEN"
      connectsTo=".B1 .J1"
      model="flexscreen_w16_h10_flex5_sitsflat"
    />
  </assembly.device>
)`}
/>

| Property | Description |
|----------|-------------|
| `name` | Required, non-empty screen name. |
| `connectsTo` | Required selector matching exactly one PCB component, `assembly.screen`, or `assembly.subassembly`. The nearest `assembly.device` scopes the search, or the circuit root if there is no device. |
| `model` | Modelprinter string or HTTP(S) model URL. |
| `modelUrl` | Imported model URL. |
| `cadModel` | Modelprinter string. |
| `width`, `height` | Positive screen body dimensions, including the bezel but excluding the flex cable. Supply both together. |

Provide one of `model`, `modelUrl`, or `cadModel`, **or** supply both `width` and `height` to generate a default FlexScreen model. Model sources are mutually exclusive. You can supply dimensions alongside an explicit model, but they do not resize it.

For example, this screen uses a generated `flexscreen_w40mm_h25mm` model:

```tsx
<assembly.screen
  name="SCREEN"
  connectsTo=".B1 .J1"
  width="40mm"
  height="25mm"
/>
```

The screen anchors to the target PCB component's cable insertion center when it has one; otherwise it uses the component center. It follows the target's orientation and top or bottom layer. For an imported display model, place its origin at the attachment point.

In circuit JSON, the screen creates a `source_component` and a `cad_component` with its resolved position, rotation, layer, and model reference. It does not create a `pcb_component` for the screen. The `connectsTo` selector is used during rendering rather than stored as an electrical connection.
