---
title: <cadassembly />
description: >-
  A CAD assembly is a collection of cad models and constraints to "put together"
  a component.
---

A CAD assembly is used to put together the 3D models of a component when multiple
models are used or "fit into" models in a particular way.

import CircuitPreview from "@site/src/components/CircuitPreview"

<CircuitPreview
  defaultView="3d"
  hidePCBTab
  hideSchematicTab
  browser3dView={false}
  code={`
  export default () => (
    <board width="10mm" height="10mm">
      <chip
        name="J1"
        cadModel={
          <cadassembly>
            <cadmodel
              positionOffset={{ x: 0, y: -4, z: 0 }}
              rotationOffset={{ x: 0, y: 0, z: 0 }}
              model="pinrow4"
            />
            <cadmodel
              positionOffset={{ x: 0, y: 4, z: 0 }}
              rotationOffset={{ x: 0, y: 0, z: 0 }}
              model="pinrow4"
            />
          </cadassembly>
        }
      />
    </board>
  )
  `}
/>

For device-level mechanical parts such as housings and screws, use
[`assembly.subassembly`](./assembly-subassembly.mdx). See
[Mounting 3D models to a board](../guides/tscircuit-essentials/mounting-3d-models.mdx)
for an example with imported screws aligned to PCB holes.
