`assembly.drawing.page` defines a paper sheet for outline drawings of an assembly or board. Give each page a unique `name` to select it during CLI export.

## Properties

| Property | Description |
|----------|-------------|
| `name` | Page name used by `tsci build --drawing` and `tsci export --drawing`. |
| `displayName` | Optional human-readable page label. |
| `size` | Standard paper size: `iso_a0` through `iso_a4`, or `ansi_a` through `ansi_e`. |
| `orientation` | `landscape` (default) or `portrait`, when using `size`. |
| `width`, `height` | Both required for a custom sheet. Numbers are millimetres; unit strings such as `"210mm"` also work. Use these instead of `size` and `orientation`. |
| `anchorAlignment` | Coordinate anchor: `center` (default), `top_left`, `top_center`, `top_right`, `center_left`, `center_right`, `bottom_left`, `bottom_center`, or `bottom_right`. |
| `children` | One or more [`assembly.drawing.partview`](./assembly-drawing-partview.mdx) or [`assembly.drawing.explosionview`](./assembly-drawing-explosionview.mdx) elements, [`notes`](./assembly-drawing-note.mdx), and optionally one [`assembly.drawing.titleblock`](./assembly-drawing-titleblock.mdx). |

Choose either a standard `size` or custom `width` and `height`. Page dimensions describe paper, not the physical assembly. A page needs at least one part or explosion view to export.

To annotate measurements, put [`assembly.drawing.dimension`](./assembly-drawing-dimension.mdx) elements inside either kind of view. Dimensions can measure view extents, named CAD outlines, hole spacing, and edge-to-hole offsets.

## Page coordinates

`anchorAlignment` chooses where `(0, 0)` lies on the sheet. View centers and annotation `paperX`/`paperY` values are relative to that anchor. Axes always remain positive X right and positive Y up. For `bottom_left`, positions inside the sheet are positive; for `top_left`, positions below the top edge use negative Y.

Annotations can instead use `xOffsetFromViewCenter` and `yOffsetFromViewCenter` to follow a view. Each axis chooses either a page-relative coordinate or a view-relative offset. See the [fidget explosion example](./assembly-drawing-explosionview.mdx) for a bottom-left anchored sheet with both kinds of positioning.

## Export the page

Save the example as `carrier.circuit.tsx`:

```bash
tsci build carrier.circuit.tsx --drawings
tsci export carrier.circuit.tsx --drawing carrier-inspection
```

Build writes `dist/carrier/drawings/carrier-inspection.svg`. Export writes `carrier-inspection.svg` beside the input file. To select by generated filename and choose a destination:

```bash
tsci export carrier.circuit.tsx --drawing carrier-inspection.svg --output inspection.svg
```

`name` is the page identity, not a path. The CLI makes a safe SVG filename from it, replacing spaces and other unsupported filename characters with hyphens. Unnamed pages use `drawing-1.svg`, `drawing-2.svg`, and so on, in page order. Use unique page names; colliding filenames are rejected.

See [`tsci build`](/command-line/tsci-build#drawing-sheets) for exporting every page and [`tsci export`](/command-line/tsci-export#exporting-drawing-sheets) for single-page selection and output paths.
