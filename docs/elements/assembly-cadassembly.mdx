`assembly.cadassembly` is an alias for [`assembly.subassembly`](./assembly-subassembly.mdx). It has the same props, placement rules, and CAD-only behavior.

<CircuitPreview

const models =
  "https://docs.tscircuit.com/models/assembly"

export default () => (
  <assembly.device name="product">
    <board
      width="40mm"
      height="30mm"
      thickness="1.6mm"
    />
    <assembly.cadassembly
      name="housing"
      modelUrl={models + "/housing.glb"}
    >
      <cadmodel
        modelUrl={models + "/cover.glb"}
        pcbZ={4}
      />
    </assembly.cadassembly>
  </assembly.device>
)`}
/>

The preview uses bundled demo housing and cover models. Replace their URLs with your own assets. The unnamespaced [`<cadassembly>`](./cadassembly.mdx) remains available for grouping models inside a component's `cadModel`. Use the namespaced element for device-level mechanical parts alongside a board.

Like `assembly.subassembly`, this alias accepts `model="flexscreen_w16_h10_flex5_sitsflat"` or other modelprinter strings, resolved to GLB models on modelcdn. `model` also accepts direct HTTP(S) model URLs, with the same file format detection and `#ext` hints as `modelUrl`. Choose only one of `model`, `modelUrl`, and `cadModel`. See the [model string reference](./assembly-subassembly.mdx#modelprinter-strings).
