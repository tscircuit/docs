`assembly.cadassembly` is an alias for [`assembly.subassembly`](./assembly-subassembly.mdx). It has the same props, placement rules, and CAD-only behavior.

    </assembly.cadassembly>

The preview uses bundled demo housing and cover models. Replace their URLs with your own assets. The unnamespaced [`<cadassembly>`](./cadassembly.mdx) remains available for grouping models inside a component's `cadModel`. Use the namespaced element for device-level mechanical parts alongside a board.

Like `assembly.subassembly`, this alias accepts `model="flexscreen_w26.7mm_h19.26mm_sitsflat"` or other modelprinter strings, resolved to GLB models on modelcdn. `model` also accepts direct HTTP(S) model URLs, with the same file format detection and `#ext` hints as `modelUrl`. Choose only one of `model`, `modelUrl`, and `cadModel`. See the [model string reference](./assembly-subassembly.mdx#modelprinter-strings).
