## Overview

`<netlabel />` places a small label on a schematic net so you can easily
identify power rails and other connections. It is especially useful in
conjunction with the `connections` prop of components or modules to
show where a net connects.

## Inline Labels

Set `inline` to place the net name along the connected schematic trace instead
of beside its port. Placement is automatic, so `schX`, `schY`, `schRotation`,
and `anchorSide` do not position an inline label. If the schematic trace solver
cannot find a collision-free inline position, tscircuit falls back to an
anchored label.

## Properties

| Property | Description | Example |
| -------- | ----------- | ------- |
| `net` | Name of the net that the label represents | `"VCC"` |
| `connectsTo` | One or more [port selectors](../guides/tscircuit-essentials/port-and-net-selectors.md) that the label attaches to | `"U1.VCC"`, `["U1.VCC", "U2.VCC"]` |
| `connection` | Legacy singular port selector that the label attaches to | `"U1.VCC"` |
| `inline` | Places the net name along its connected schematic trace using automatic, collision-aware placement. Anchored positioning props are ignored while active. | `true` |
| `anchorSide` | Which side of the connection to place the label. One of `"top"`, `"bottom"`, `"left"`, or `"right"` | `"top"` |
| `schX`, `schY` | Position of the label on the schematic | `0`, `-1` |

Use `<netlabel />` to clearly mark nets in your schematic, especially for
power rails or when multiple wires join at a single connection point.
