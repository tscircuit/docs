## Overview

`<netlabel />` places a small label on a schematic net so you can easily
identify power rails and other connections. It is especially useful in
conjunction with the `connections` prop of components or modules to
show where a net connects.

## Properties

| Property | Description | Example |
| -------- | ----------- | ------- |
| `net` | Name of the net that the label represents | `"VCC"` |
| `connectsTo` | One or more [port selectors](../guides/tscircuit-essentials/port-and-net-selectors.md) the label attaches to | `"U1.VCC"`, `["U1.VCC", "U2.VCC"]` |
| `connection` | Singular port selector the label attaches to | `"U1.VCC"` |
| `inline` | Places the net name automatically along its schematic trace. `schX`, `schY`, `schRotation`, and `anchorSide` are ignored while this is set. If a trace placement cannot be found, core falls back to an anchored label. | `true` |
| `anchorSide` | Which side of the connection to place an anchored label. One of `"top"`, `"bottom"`, `"left"`, or `"right"` | `"top"` |
| `schX`, `schY` | Position of an anchored label on the schematic. Ignored when `inline` is active. | `0`, `-1` |
| `schRotation` | Rotation of an anchored label. Ignored when `inline` is active. | `90` |

Use `<netlabel />` to clearly mark nets in your schematic, especially for
power rails or when multiple wires join at a single connection point.

`<netlabel inline />` is the compact form for a net that already has a
schematic trace: the name is drawn on the wire instead of as a separate
anchored box.
