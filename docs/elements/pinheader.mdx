## Overview

The `<pinheader />` element is used to create a male or female pin header
with configurable spacing and number of pins.

import CircuitPreview from "@site/src/components/CircuitPreview"

## Example

<CircuitPreview
  defaultView="schematic"
  code={`export default () => (
   <board width="30mm" height="10mm">
    <pinheader
      name="J1"
      pinCount={8}
      gender="male"
      pitch="2.54mm"
      footprint="pinrow8_rows2"
      doubleRow={true}
      showSilkscreenPinLabels={true}
      pinLabels={["VCC", "GND", "SDA", "SCL", "MISO", "MOSI", "SCK", "CS"]}
      pcbX={0}
      pcbY={0}
    />
   </board>
  )
`}
/>

## Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| pinCount | number | (required) | Number of pins in the header |
| pitch | number \| string | "2.54mm" | Distance between pins |
| schFacingDirection | "up" \| "down" \| "left" \| "right" | "right" | Direction the header faces in schematic view |
| gender | "male" \| "female" \| "unpopulated" | "male" | Whether the header is male, female, or left unpopulated |
| connectsFromAbove | boolean | omitted (`false`) | Mounts the header on the top layer, describing a mating connector that approaches from above. |
| connectsFromBelow | boolean | omitted (`false`) | Mounts the header on the bottom layer, describing a mating connector that approaches from below. |
| showSilkscreenPinLabels | boolean | false | Whether to show pin labels in silkscreen |
| doubleRow | boolean | false | Whether the header has two rows of pins |
| holeDiameter | number \| string | "1mm" | Diameter of the through-hole for each pin |
| platedDiameter | number \| string | "1.7mm" | Diameter of the plated area around each hole |
| pinLabels | `Record<string, string>` \| `string[]` | undefined | Labels for each pin, supplied as a pin-keyed map or an ordered array |
| facingDirection | "left" \| "right" | "right" | Direction the header is facing |
| pcbX | number | 0 | X position of the component |
| pcbY | number | 0 | Y position of the component |
| rotation | number | 0 | Rotation of the component in degrees |
| id | string | auto-generated | Unique identifier for the component |

## Choose the Mating Side

Use `connectsFromAbove` or `connectsFromBelow` when it is clearer to describe
which side a cable or mating connector approaches from:

```tsx
<pinheader
  name="J_TOP"
  pinCount={4}
  footprint="pinrow4"
  connectsFromAbove
/>

<pinheader
  name="J_BOTTOM"
  pinCount={4}
  footprint="pinrow4"
  connectsFromBelow
/>
```

`connectsFromAbove` is an alias for `layer="top"`, which is the default.
`connectsFromBelow` is an alias for `layer="bottom"`. Set at most one of the
two aliases; enabling both is invalid. If `layer` is also present, the explicit
`layer` value takes precedence.

These props choose which side of the PCB the component occupies. They are not
the same as `invert` in a footprint string, which reverses the header's pin
orientation on its current layer.
