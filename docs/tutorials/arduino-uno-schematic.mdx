## Overview

The Arduino Uno Rev3 is the reference open-source microcontroller board built around the Microchip **ATmega328P** 8-bit AVR microcontroller. Modeling an Arduino Uno schematic in tscircuit allows you to visualize, simulate, and export netlists directly using TypeScript and React components.

This tutorial walks through building the full Arduino Uno core circuit:

1. **Power Regulation Block**: 5V LDO regulation, barrel jack input, and 3.3V auxiliary rail.
2. **Microcontroller Core (ATmega328P)**: Pin definitions, power rails, and active-low reset circuitry.
3. **16 MHz Clock Oscillator**: Crystal resonator with dual 22pF load capacitors.
4. **Header Breakouts**: Standard 8-pin and 6-pin female socket strips for GPIO, analog ADC, and SPI.
5. **Status Indicator**: Built-in Pin 13 test LED with current-limiting resistor.

## Architectural Breakdown

### 1. ATmega328P Pin Configuration
The `ATMEGA328P-PU` organizes all essential signals across three logical banks:
- **Port B (PB0–PB5)**: Digital pins 8 to 13, including hardware SPI pins (`MOSI`, `MISO`, `SCK`).
- **Port C (PC0–PC5)**: Analog ADC inputs 0 to 5, where `ADC4` doubles as `SDA` and `ADC5` doubles as `SCL` (I2C).
- **Port D (PD0–PD7)**: Digital pins 0 to 7, including UART `RX`/`TX` on pins 0/1 and external interrupts `INT0`/`INT1`.

### 2. Clock Generation (16 MHz)
The AVR core requires an external high-speed clock for deterministic execution:
- Crystal **Y1** connects across `XTAL1` (pin 9) and `XTAL2` (pin 10).
- Load capacitors **C1** and **C2** (22 pF) stabilize frequency jitter and ensure clean clock transitions.

### 3. Power Supply and Voltage Regulators
- **VIN (7V–12V)** feeds into the linear regulator `NCP1117ST50T3G` to step down cleanly to **+5V**.
- Bulk electrolytic capacitors **C4** and **C5** (47 µF) filter voltage ripple on both input and output sides.
- A **100 nF** ceramic capacitor **C3** placed adjacent to the `VCC` and `AVCC` pins decouples high-frequency switching noise.

### 4. Standard Arduino Shield Compatibility
The schematic exports all connections to the canonical Arduino Rev3 2.54 mm pitch headers:
- **J1 (10-pin)**: Digital high and I2C lines (`D8`–`D13`, `GND`, `AREF`, `SDA`, `SCL`).
- **J2 (8-pin)**: Digital low and UART lines (`D0`–`D7`).
- **J3 (6-pin)**: Analog sensor lines (`A0`–`A5`).
- **J4 (8-pin)**: Power rail and system control lines (`VIN`, `5V`, `3V3`, `RESET`, `GND`).
