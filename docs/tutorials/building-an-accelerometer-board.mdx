## Overview

A **3-axis MEMS accelerometer board** measures static acceleration (gravity for tilt/orientation sensing) and dynamic acceleration (vibration, shock, motion, and free-fall). In this tutorial, you will design a complete I2C accelerometer breakout PCB (modeled around an industry-standard 8-pin/14-pin digital accelerometer interface like the **ADXL345** / **LIS3DH**) using **tscircuit**.

You will learn how to configure the sensor's schematic symbol, place high-frequency decoupling capacitors, wire I2C bus pull-up resistors, expose hardware interrupt pins (`INT1`, `INT2`), and lay out a compact breakout board ready for fabrication.

## Components Needed (Bill of Materials)

| Reference | Component | Value / Package | Purpose |
| --- | --- | --- | --- |
| `U1` | 3-Axis Digital Accelerometer | ADXL345 / LIS3DH (`soic8` / LGA breakout) | Measures X, Y, and Z acceleration and outputs digital data over I2C |
| `C1` | Ceramic Bypass Capacitor | `100nF` (`0603`) | Filters high-frequency switching noise right at the `VDD` pin |
| `C2` | Bulk Reservoir Capacitor | `10uF` (`0805`) | Stabilizes the supply voltage during internal ADC conversion bursts |
| `R_SCL`, `R_SDA` | I2C Pull-Up Resistors | `4.7kΩ` (`0603`) | Pulls open-drain `SCL` and `SDA` clock/data lines to `VCC` |
| `R_ADDR` | Address Configuration Resistor | `10kΩ` (`0603`) | Pulls `SDO`/`SA0` to `GND` to set a deterministic I2C slave address |
| `J1` | 6-Pin Breakout Header | `2.54mm` pitch (`pinrow6`) | Exposes `VCC`, `GND`, `SCL`, `SDA`, `INT1`, and `INT2` to a microcontroller |

## Key Design Concepts

### 1. Selecting I2C Mode and Device Address

Most MEMS accelerometers support both **I2C** and **SPI** serial interfaces using shared pins:

- **Chip Select (`CS`):** Tying `CS` high to `VCC` configures the sensor to communicate over **I2C** instead of 3/4-wire SPI.
- **Address Pin (`SDO` / `ALT ADDRESS`):** Pulling `SDO` low to `GND` through a `10kΩ` resistor (`R_ADDR`) selects the primary 7-bit I2C address (`0x53` on ADXL345, or `0x18` on LIS3DH).

### 2. Why Low-Noise Decoupling Matters for Accelerometers

Inside a MEMS accelerometer, microscopic capacitive plates deflect by fractions of a femtofarrad under acceleration. Noise on the `VDD` supply rail couples directly into the internal charge amplifier and analog-to-digital converter (ADC), causing jittery readings. Placing a **`100nF` ceramic capacitor (`C1`)** and a **`10uF` bulk capacitor (`C2`)** physically close to `U1`'s `VDD` pin keeps the analog front-end quiet.

### Step 4: PCB Layout & Mechanical Placement Best Practices

When laying out an accelerometer PCB, follow these hardware engineering guidelines:

1. **Place `C1` (`100nF`) Immediately Adjacent to `VDD`:** Minimize loop inductance on the high-frequency bypass path.
2. **Rigid Mounting:** Place the accelerometer IC (`U1`) near the center or mounting point of the PCB where mechanical board flex and resonance are minimized.
3. **Avoid Heat Sources:** Keep the MEMS package away from high-power regulators to prevent thermal zero-g offset drift.

## Reading 3-Axis Acceleration over I2C

Once you wire `VCC` (`3.3V`), `GND`, `SCL`, and `SDA` from header `J1` to a microcontroller (such as an RP2040, ESP32, or Arduino), you can enable measurement mode and stream X, Y, and Z acceleration values:

```cpp
#include <Wire.h>

#define ACCEL_ADDR 0x53 // Default I2C address when SDO is pulled to GND

void setup() {
  Serial.begin(115200);
  Wire.begin();

  // Put ADXL345 into Measurement Mode (Register 0x2D, Bit D3 = 1)
  Wire.beginTransmission(ACCEL_ADDR);
  Wire.write(0x2D);
  Wire.write(0x08);
  Wire.endTransmission();
}

void loop() {
  Wire.beginTransmission(ACCEL_ADDR);
  Wire.write(0x32); // Start at DATAX0 register
  Wire.endTransmission(false);
  Wire.requestFrom(ACCEL_ADDR, 6, true);

  int16_t rawX = Wire.read() | (Wire.read() << 8);
  int16_t rawY = Wire.read() | (Wire.read() << 8);
  int16_t rawZ = Wire.read() | (Wire.read() << 8);

  // Convert raw LSB (~3.9 mg/LSB in +/-2g full-resolution mode) to g
  Serial.print("X: "); Serial.print(rawX * 0.0039); Serial.print(" g, ");
  Serial.print("Y: "); Serial.print(rawY * 0.0039); Serial.print(" g, ");
  Serial.print("Z: "); Serial.print(rawZ * 0.0039); Serial.println(" g");
  delay(100);
}
```
