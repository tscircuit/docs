## Overview

In this tutorial, you will build an **ESP32 reference schematic** following official [Espressif Hardware Design Guidelines](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32/schematic-checklist.html).

Designing a reliable microcontroller schematic requires properly addressing:
1. **Power Supply & Decoupling**: Regulated 3.3V rail with high-frequency ceramic capacitors to absorb Wi-Fi RF power bursts.
2. **Power-On Reset (EN / CHIP_PU)**: RC timing filter (10k ohm resistor + 1uF capacitor) to guarantee smooth, monotonic power ramps and prevent brownout hangs.
3. **Boot Strapping Circuit (GPIO0)**: Dual-state pull-up configuration enabling normal SPI flash execution and UART firmware flashing mode.
4. **Fast Schematic Rendering**: Using `routingDisabled` on the `<board />` element to bypass PCB trace calculation when focusing purely on schematic capture.

## Critical Hardware Design Rules

According to the Espressif Hardware Design Guidelines, four fundamental considerations must be maintained in every ESP32 schematic:

### 1. Power-On Reset (EN / CHIP_PU) Timing
The `EN` (Chip Power Up) pin must not reach logic HIGH until the power supply rail has stabilized above 2.8V. 
- To prevent glitch resets during power-up ramps, Espressif specifies an **RC timing circuit**: a 10kΩ pull-up resistor (`R_EN`) paired with a 1µF capacitor (`C_EN`) to ground.
- Pressing `SW_RESET` grounds the `EN` pin, allowing manual hardware resets without power cycling.

### 2. Boot Strapping Configuration (GPIO0 & GPIO2)
The ESP32 samples strapping pins upon reset release to determine the boot mode:
- **Normal SPI Flash Boot**: `GPIO0` must be pulled HIGH (`1`).
- **UART Download Flashing Boot**: `GPIO0` must be pulled LOW (`0`).
- By adding a 10kΩ pull-up resistor to 3.3V and a momentary pushbutton (`SW_BOOT`) to ground, the ESP32 defaults to normal boot while allowing download mode at the press of a button.

### 3. Decoupling Capacitors for Wi-Fi Transients
During Wi-Fi transmit bursts, the ESP32 internal power amplifier can draw instantaneous current pulses exceeding 500mA.
- Place a **10µF bulk capacitor** (`C1`) alongside a **0.1µF ceramic capacitor** (`C2`) directly beside the `3V3` pin.
- The 0.1µF capacitor suppresses high-frequency switching noise, while the 10µF capacitor prevents rail drops during RF transmission.

### 4. Fast Schematic Iteration with `routingDisabled`
When drafting complex microcontroller schematics with dozens of nets and passive subcircuits, PCB autorouting can consume unnecessary build cycles.
By adding the `routingDisabled` property to the root `<board />` element:
```tsx
<board width="65mm" height="55mm" routingDisabled>
  {/* Components and schematic layout */}
</board>
```
tscircuit compiles the schematic instantly, letting you design, review, and iterate on circuit topologies at maximum speed.

## Summary

Following official hardware reference guidelines ensures your ESP32 circuits boot reliably under all operating conditions. With tscircuit's declarative React syntax and the `routingDisabled` property, you can capture professional schematics with complete timing and decoupling integrity in minutes.
