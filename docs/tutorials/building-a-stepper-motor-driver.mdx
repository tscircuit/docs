## Overview

A **bipolar stepper motor driver board** translates low-current `STEP` and `DIR` logic pulses from a microcontroller into high-current, PWM-chopped H-bridge coil currents (`A1`/`A2` and `B1`/`B2`) capable of driving NEMA 17 and NEMA 23 stepper motors with precise microstepping.

In this tutorial, you will design a complete stepper motor driver carrier board (modeled around a standard dual H-bridge microstepping driver IC such as the **A4988** / **DRV8825**) using **tscircuit**.

| Reference | Component | Value / Package | Purpose |
| --- | --- | --- | --- |
| `U1` | Bipolar Stepper Driver IC | A4988 / DRV8825 (`tssop16`) | Dual full-bridge MOSFET driver with built-in microstepping translator |
| `J_CTRL` | 6-Pin Logic Header | `2.54mm` pitch (`pinrow6`) | Connects microcontroller `VDD` (`3.3V`/`5V`), `GND`, `STEP`, `DIR`, `MS1`, `EN` |
| `J_MOT` | 6-Pin Motor & Power Header | `2.54mm` pitch (`pinrow6`) | Connects motor supply `VMOT` (`8V–35V`), `GND`, and coils `A1`, `A2`, `B1`, `B2` |
| `R_SA`, `R_SB` | Current-Sense Resistors | `0.1Ω` (`1206`, `0.5W`+) | Measures coil current for the internal PWM constant-current chopper |
| `R_SLP` | Reset/Sleep Pull-Up Resistor | `10kΩ` (`0603`) | Holds `RST` and `SLP` high to keep the driver awake by default |
| `C_VDD` | Logic Bypass Capacitor | `100nF` (`0603`) | Decouples the `3.3V`/`5V` digital logic supply |
| `C_VMOT` | Bulk Motor Supply Capacitor | `47uF` (`1210`, `50V` rated) | Absorbs inductive kickback and supplies peak coil switching currents |

## How a Chopper Stepper Motor Driver Works

### 1. STEP and DIR Interface

Instead of energizing individual H-bridge transistors from software, a microstepping translator IC advances its internal sine/cosine current table on every rising edge of the **`STEP`** pin. The logic level on **`DIR`** (`HIGH` or `LOW`) determines whether the motor shaft rotates clockwise or counter-clockwise.

### 2. Constant-Current PWM Regulation (`R_SA` and `R_SB`)

Stepper motor coils have low winding resistance (`1Ω–3Ω`). Driving them directly from `12V` or `24V` minimizes inductive rise time at high RPMs, but requires active current limiting to prevent overheating. The driver monitors the voltage across low-value sense resistors (`R_SA = 0.1Ω`, `R_SB = 0.1Ω`). For an A4988-class driver, the peak trip current `I_MAX` is set by:

```text
I_MAX = V_REF / (8 * R_SENSE)
```

With `R_SENSE = 0.1Ω` and `V_REF = 0.8V`, the driver regulates each coil to `I_MAX = 0.8V / 0.8Ω = 1.0A`.

### Step 3: PCB Layout and High-Current Routing Guidelines

When laying out a stepper driver PCB, keep these power-electronics layout rules in mind:

1. **Short Sense-Resistor Ground Paths:** Place `R_SA` and `R_SB` (`1206`) close to the driver IC with direct, low-inductance connections to `GND` so switching spikes do not falsely trip the current comparator.
2. **Place `C_VMOT` Close to `VMOT` and `GND`:** The `47uF` bulk capacitor handles rapid current reversals when the H-bridges chop coil current.
3. **Separate Logic and Motor Sides:** Place the microcontroller header (`J_CTRL`) on the left edge of the board and the high-voltage motor header (`J_MOT`) on the right edge.

## Driving the Stepper Motor from Firmware

Connect `J_CTRL` to your microcontroller (`STEP` -> `GPIO 2`, `DIR` -> `GPIO 3`, `EN` -> `GND`) and connect a `12V–24V` supply plus your bipolar stepper motor coils to `J_MOT`:

```cpp
const int STEP_PIN = 2;
const int DIR_PIN  = 3;
const int STEPS_PER_REV = 200; // 1.8 deg/step NEMA 17 motor in full-step mode

void setup() {
  pinMode(STEP_PIN, OUTPUT);
  pinMode(DIR_PIN, OUTPUT);
}

void stepMotor(int steps, bool clockwise, int pulseDelayUs) {
  digitalWrite(DIR_PIN, clockwise ? HIGH : LOW);
  for (int i = 0; i < steps; i++) {
    digitalWrite(STEP_PIN, HIGH);
    delayMicroseconds(pulseDelayUs);
    digitalWrite(STEP_PIN, LOW);
    delayMicroseconds(pulseDelayUs);
  }
}

void loop() {
  // Rotate 1 full revolution clockwise
  stepMotor(STEPS_PER_REV, true, 800);
  delay(500);

  // Rotate 1 full revolution counter-clockwise
  stepMotor(STEPS_PER_REV, false, 800);
  delay(500);
}
```
