## Checkpoint

Before Part 2, you should be able to:

- [ ] write a source, a probe and an analysis from memory;
- [ ] pick `duration` and `timePerStep` for the signal you care about;
- [ ] find your node in the ngspice table;
- [ ] check a result on paper.
