This course is for electrical engineers who are new to tscircuit. It takes you
from a voltage divider to an eye diagram on a routed DDR3 trace. Each lesson
adds **one** new idea and ends with a check you can do on paper.

You don't need to know React. A tscircuit file is a function that returns your
circuit as tags. `<resistor>` is a resistor, `<trace>` is a connection, and
`tsci simulate` runs the analysis you declare.

## Lesson status

Each lesson starts with a status badge:

- **✅ Runs today.** We ran the code with `tsci simulate`, and the numbers on
  the page come from that run.
- **🟡 Not run yet.** The code uses elements tscircuit already has, but nobody
  has run this exact example yet. Expect to adjust it.
- **🚧 Not supported yet.** This is the setup we're aiming for. The page says
  what's missing today.

## How every lesson is laid out

1. **Goal:** one sentence.
2. **Build:** one `*.circuit.tsx` file.
3. **Run:** `bunx tsci simulate <file>`.
4. **What you see:** the real output.
5. **Check by hand:** the paper calculation it should match.
6. **Try this:** one change to make on your own.

## Before you start

```bash
bun install -g tscircuit     # or use bunx tsci in a project
brew install ngspice         # Part 1 onwards
# Part 2 onwards (pcb_spice): fasthenry and FasterCap on your PATH
```

### Reading `tsci simulate` output

The ngspice engine prints a table. Columns are **node voltages**
(`v(n1)`, `v(n2)`, …) and source currents, not your probe names. In a small
circuit, find your node by its value. Lesson 1 shows how.
