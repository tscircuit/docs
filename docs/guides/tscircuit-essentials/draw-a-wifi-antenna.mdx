# Draw a WiFi Antenna

Use [`<antenna />`](../../elements/antenna.mdx) when you want a placed component
with an open-ended copper shape, such as a printed WiFi antenna. Define a
one-pad footprint for its feed, place the feed with `pcbX` and `pcbY`, and draw
the antenna geometry with `pcbPath`.

<CircuitPreview leftView="code" rightView="pcb" code={`
  export default () => (
    <board width="32mm" height="16mm" minTraceWidth="0.3mm">
      <chip name="U1" footprint="qfn32" pcbX={-12} />
      <antenna
        name="ANT1"
        pcbX={-8}
        pcbY={-1}
        footprint={
          <footprint>
            <smtpad
              shape="rect"
              width="1mm"
              height="1mm"
              portHints={["pin1"]}
            />
          </footprint>
        }
        pcbPath={[
          { x: 1, y: 0 },
          { x: 1, y: 5 },
          { x: 12, y: 5 },
          { x: 12, y: 3.5 },
          { x: 3, y: 3.5 },
          { x: 3, y: 2 },
          { x: 12, y: 2 },
          { x: 12, y: 0.5 },
          { x: 3, y: 0.5 },
          { x: 3, y: -1 },
          { x: 12, y: -1 },
        ]}
      />
      <trace from=".U1 > .pin1" to=".ANT1 > .feed" />
    </board>
  )
`} />

The antenna route begins at the footprint's `pin1` pad automatically. Each
coordinate object is measured in millimeters relative to that feed, so changing
`pcbX`, `pcbY`, or `pcbRotation` moves the footprint and copper shape together.
The separate `<trace />` connects the RF chip to the antenna's `feed` alias.

Set `minTraceWidth` on the board or subcircuit to control the antenna copper
width. The path can also use selector strings and via entries supported by
[`<trace pcbPath>`](../../elements/trace.mdx#manual-pcb-paths).

:::caution

This meander is an API example, not a tuned 2.4 GHz antenna. Copy dimensions,
board stackup, feed impedance, and ground-clearance requirements from a
validated antenna design. Use a [`<keepout />`](../../elements/keepout.mdx) to
preserve the required copper-free region.

:::
