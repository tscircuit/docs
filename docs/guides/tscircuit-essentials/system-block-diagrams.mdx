Use system blocks to explain what a circuit does. This wireless sensor node
collects measurements, processes them, and transmits them through a radio.

## Describe the system

Start with a [`systemblock.page`](../../elements/systemblock-page.mdx). Add a
[`systemblock.component`](../../elements/systemblock-component.mdx) for each
function, and use a [`systemblock.group`](../../elements/systemblock-group.mdx)
to collect related functions. Connect the blocks with
[`systemblock.connection`](../../elements/systemblock-connection.mdx) elements
that name the interfaces between them.

<CircuitPreview code={systemBlockExample} defaultView="system" hidePCBTab hideSchematicTab hide3DTab hideCodeTab verticalStack />

Here, the sensor and microcontroller belong to the same subsystem. The I2C and
SPI connections have arrows at both ends to indicate two-way communication.
The page's `direction="down"` arranges the flow vertically. Core chooses block
sizes, positions, routes, and label positions automatically.

The preview is rendered from this TSX by svg.tscircuit.com using `circuit-to-svg`. Exported System
SVGs work independently of the editor's available tabs. Save the example as
`system-blocks.circuit.tsx` to use it in the export below.

## Render an SVG

The `tscircuit` package re-exports the `systemblock` namespace from `@tscircuit/core`.

```tsx
import { Circuit } from "tscircuit"
import { convertCircuitJsonToSystemSvg } from "circuit-to-svg"
import SystemOverview from "./system-blocks.circuit"

const circuit = new Circuit()
circuit.add(<SystemOverview />)
await circuit.renderUntilSettled()
const json = circuit.getCircuitJson()
const svg = convertCircuitJsonToSystemSvg(json, {
  width: 1000,
})
```

This exports the first system block page. Pass the generated circuit output
directly to the converter; no inspection or editing is needed.
