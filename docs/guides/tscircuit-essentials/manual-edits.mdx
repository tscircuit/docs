`manual-edits.json` is a data format that can apply serialized PCB placement,
PCB trace-hint, and schematic-placement edits to a circuit.

:::warning
The standard viewers in [tscircuit.com](https://tscircuit.com) and `tsci dev`
currently do not expose GUI controls for creating manual edits. In particular,
the schematic pencil button and the PCB **Edit Trace** and **Move Components**
controls described in earlier versions of this guide are no longer available.
:::

For new circuit layouts, use [layout properties](./layout-properties.mdx), such
as `pcbX`, `pcbY`, `schX`, and `schY`, instead.

## Applying an Existing Manual Edits File

You can import an existing or externally generated `manual-edits.json` file and
pass it to the `manualEdits` prop of a `<board />` or `<subcircuit />`:

```tsx
import manualEdits from "./manual-edits.json"

export default () => (
  <board width="10mm" height="10mm" manualEdits={manualEdits}>
    {/* ... */}
  </board>
)
```

## Manual Edits Format

The format is defined in [the manual-edits type](https://github.com/tscircuit/props/blob/main/lib/manual-edits/manual_edits_file.ts).
It contains three kinds of edits:

- `pcb_placements` for component positions on the PCB
- `manual_trace_hints` for PCB trace-routing hints
- `schematic_placements` for component positions on the schematic

An empty manual-edits file is valid JSON and can be used as a starting point
for a tool that generates edits:

```json
{
  "pcb_placements": [],
  "manual_trace_hints": [],
  "schematic_placements": []
}
```
